# Web 管理面板约定

通用约定与高频硬规则见仓库根目录 `AGENTS.md`；本文件记录面板前端与安全/布局交互的完整规格。

## 监听、认证与敏感配置

- 面板默认只监听 `127.0.0.1`；可在部署配置中指定具体的监听地址（如部署机局域网 IP）以供局域网访问，拒绝 `0.0.0.0`、`::` 等全部网卡地址。HTTPS 不强制：是否启用、使用哪个证书由管理员在部署配置中选择，不生成自签名证书；配置了证书但无法加载时不以明文 HTTP 对外监听。
- 使用长度 64 的随机 Token 登录，Token 在部署配置生成和保存，不硬编码，不随前端配置或静态产物下发。登录以 Token 换取 HttpOnly、SameSite=Strict 的 Cookie 会话，有效期 7 天并在活动时续期；会话签名密钥持久化到本地；登录失败按来源限速；提供退出登录；重新生成 Token 后全部现有会话失效。
- 提供总览、Bot 状态、模块管理、数据统计、按群聊和私聊分别统计的聊天数据、日志、配置和插件配置。
- 敏感配置（DSN、RustFS 密钥、LLBot AccessToken、HTTPS 证书密码、面板 Token）与插件机密（如图源服务令牌、B站登录状态）只存于本地文件，Web 只写不回显：显示已配置/未配置，输入新值即替换，可选项可清除（需确认）；接口与日志不返回、不记录其值。宿主的数据库、LLBot、RustFS 与 HTTPS 证书配置（含非敏感项）修改时，保存前用修改后的整组值实际连接或加载（数据库另拒绝超级用户，RustFS 的 IM 可达地址只校验格式），通过才写入；面板 Token 只能重新生成。插件经 `UseSecrets` 声明机密类型后，插件页显示机密表单：字符串项可写且保存即时生效，其他项（如扫码登录结果）只显示状态并由插件经宿主接口写入；插件机密按插件分文件，管理员也可直接编辑文件（重启后生效）。其他宿主配置可在 Web 修改，仅在保存时提示是否需要重启生效，不在界面上逐项标注。

## 技术栈、主题与布局

- 使用 pnpm、Vue（单文件组件与 TypeScript，尽量避免手写 JS）、Tailwind CSS、daisyUI，图标使用 Phosphor。自带插件的页面源码位于 `web/plugins/` 工作区包，所用 Tailwind 类由面板一并生成，通过 import map 共享宿主的 Vue 与 `plugin-sdk`。
- 不设置全宽顶部标题栏：页面标题与明暗切换按钮位于内容区顶部，明暗切换在右侧。侧边导航不能收缩，按分组展示，可提供二级菜单，底部显示 Bot 状态与退出登录。
- 亮色主题为 daisyUI `emerald`，暗色主题为 `dim`。颜色遵循 daisyUI 语义色与颜色变量，禁止自行硬编码配色或创造另一套视觉风格；亮色主题下图表、链接与状态文字向 base-content 混色以保证对比度。
- 分页内模块采用单列 Card 分区。默认无背景图，页面与面板为纯色；上传背景图后背景等比铺满页面，背景图本身不透明，可分别调节“侧边面板”（侧边栏与日志面板）、“内容区卡片”（内容区 Card、页面工具栏与底部操作栏）和“内容区遮罩”三个不透明度，并可开启磨砂模糊（默认关闭）。背景图经 Web 上传后与外观设置一起保存在部署数据目录的本地文件，不依赖数据库或 RustFS；外观为部署级设置。
- 非日志页面右侧停靠实时日志面板，可拖动调整宽度、可收起，宽度与收起状态按浏览器本地保存；日志参数按值类型着色，异常堆栈默认折叠。进入日志页后隐藏该面板，改由日志页展示实时日志，避免重复订阅。
- 只滚动分页内容：背景、侧边导航、页面标题、页面工具栏（如统计筛选器、日志标签）与底部操作栏（如宿主配置的保存栏）保持固定。日志页本身不滚动，只滚动实时日志列表、历史日志文件列表与文件内容。
