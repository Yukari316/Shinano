# Shinano.Tool 约定

通用约定与高频硬规则见仓库根目录 `AGENTS.md`；本文件记录运维工具、发布包、初始化、升级与系统服务管理的完整规格。

## 工具边界与跨平台

- 支持 Windows 和 Linux；初始化与运维脚本同时提供 PowerShell 7 和 sh 版本，逻辑由独立的工具工程 `Shinano.Tool` 实现一份，脚本只是它的入口。
- 工具不引用主工程，自行维护配置键名等约定，由契约测试（`ToolContractTests`、`HsoImportContractTests`）保证与宿主及插件一致。

## 发布包与部署目录

- 发布包按平台（`win-x64`、`linux-x64`）自带运行时，只含目标平台的原生库；目录为 `host/`（宿主与工具）、`monitor/`、`bundled-plugins/`、`scripts/`，部署数据目录 `data/` 与程序目录分开，由脚本和服务定义通过 `SHINANO_DATA_DIR` 指定。解压后可直接初始化或运行。

## 首次初始化与服务管理

- 首次部署使用同一个交互式初始化脚本（PowerShell 7 与 sh）：逐项询问部署配置（时区、bucket 前缀、PostgreSQL、RustFS 内部及 IM 可达地址与密钥、LLBot、Super User、运行方式（直接运行或服务管理器）、面板与状态页的监听地址和端口、可选的 HTTPS 证书），每项提供可直接确认的默认值；生成 64 位面板 Token 写入部署配置，只在结束时显示一次。
- 可选输入数据库管理员凭据以创建数据库与业务角色（数据库归管理员所有，业务角色获授 `CONNECT`、`CREATE`、`TEMP`，不创建扩展）并核验版本（PostgreSQL 18+）、UTF8 编码与 lz4，凭据不保存，否则跳过；保存前用 DSN 实际连接，账号为超级用户时拒绝保存。
- 服务管理器模式下，有权限或可提权（Windows 经 UAC，Linux 经 sudo）时由工具直接创建并启动服务，Linux 可选创建专用用户 `shinano`；无法取得权限或非交互运行时输出命令由管理员执行。
- 工具同时提供服务的启动、停止、状态与卸载，卸载只删除服务与经确认的专用用户，不删除部署目录、数据库与 bucket。修改系统状态的操作同时写入控制台与部署数据目录的 `tool.log`。
- 是否启用 HTTPS 及使用哪个证书由管理员选择，脚本不生成自签名证书。支持参数化非交互运行；已有部署配置时以现有值为默认值，不覆盖未修改项和已生成的 Token。

## 升级与随包插件

- 升级由新包中的升级脚本对目标部署执行（支持 `--yes` 与 `--accept-defaults`）：直接运行模式要求宿主、监控与运行守护进程均已停止；服务模式核验系统服务（不静默回落直接运行）并取得权限后由工具停止服务，替换完成后按实际运行用户恢复属主（Linux）、启动并等待就绪，并核对重启计划执行结果。
- 按 SemVer 2.0 拦截主程序降级，同版本交互默认否询问重装。程序目录整体替换，保留两个进程的 `Logs/` 与监控探测记录，旧版保留最近一份于 `.previous/`，替换失败时还原；数据库不回退，升级前提示备份。升级不询问配置，新增配置项取默认值。
- 随包插件视为 Bot 原生功能，以与面板上传相同的插件包 zip 交付并保留在部署中；首次初始化时装入插件目录且默认不启用；升级时已安装且新包版本严格更高的（按 SemVer 2.0 比较）暂存并写入只含本次随包升级项的重启计划（`data/restart/plan.json`），宿主首次启动自动应用并做加载验证与失败回滚（不覆盖同插件已有手动暂存，不吞入其他手动暂存），新增的直接装入且不启用，管理员删除过的不再装回。
