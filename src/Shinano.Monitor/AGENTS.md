# Shinano.Monitor 约定

通用约定与高频硬规则见仓库根目录 `AGENTS.md`；本文件记录独立监控进程与状态页的完整规格。

- 提供独立于主进程的监控进程，托管一个单独的服务状态页，监视主进程及其依赖服务的可用性。监控是独立网站，与主工程互不引用、独立部署，只通过公开接口探测；配置只读主部署的配置文件，自身设置位于其中的 `Shinano:Monitor`，由主进程宿主配置页修改。只做可用性监视，不实现 FlashDuty 式的值班、告警编排等复杂功能。
- 监视主进程健康接口（汇总数据库、RustFS、LLBot 状态），并直接探测 PostgreSQL、RustFS 与 LLBot，主进程停止时仍能显示依赖状态。
- 监听地址规则与管理面板相同（默认 `127.0.0.1`，拒绝 `0.0.0.0`、`::` 等全网卡地址），页面只读、无需登录，不显示凭据或 DSN。告警只体现在状态页和日志，不通过 IM 发送。
- 探测记录写入本地文件并保留 7 天，状态页显示各服务可用率，不依赖 PostgreSQL。
- 监控进程不负责重启或拉起主进程；服务管理器模式下作为独立服务运行，直接运行模式下由 `Shinano.Tool run` 一并启动。前端与管理面板同一 pnpm 工作区、同一主题，管理面板提供状态页链接。
