# Gemini 对话插件约定

插件 ID `gemini`。通用约定见仓库根目录 `AGENTS.md`；本文件只记录本插件的业务规则。

- **接入协议与凭据**：采用原生 Google Gemini `generateContent` REST API，支持自定义 Base URL 与可选 HTTP 代理；API Key 存于插件机密（`IPluginSecrets`），面板只写不回显。模型与思考深度（effort）在插件专有页面配置，后端通过 `GET {BaseUrl}/v1beta/models` 拉取支持 `generateContent` 的模型列表并支持手动输入，默认模型为 `gemini-4-hydrogen`、默认 effort 为 `medium`。
- **模型能力与 Effort**：结合 API 返回的 `thinking` 布尔值与内置模型族规则表动态给出可选 effort（`thinking == false` 禁用 effort；`gemini-4-hydrogen` / `gemini-4-neon` 为 `default/low/medium/high/xhigh`；其余 `gemini-4-*` 为 `default/low/medium/high`；`gemini-3-*` 为 `default/minimal/low/medium/high`；`gemini-2.5-*` 仅 `default`；未知新模型回退全集），切换模型时自动校正不兼容的 effort。多轮历史按 Gemini 3/4 协议保留 `thoughtSignature`。
- **触发与响应范围**：通过普通事件订阅 `MessageReceivedEvent` 监听可配置前缀（默认 `#`），支持前缀后可选空白，命中后终止事件链，纯前缀且无图片时静默忽略。响应范围固定为**仅白名单**（空名单不做任何响应），私聊仅限好友私聊（忽略临时会话），对 Bot Super User 同样生效；白名单与模型设置存于数据库全局 schema（切换机器人账号后保留），保存即时生效。
- **多模态输入**：提取当前消息及所引用消息（未内嵌正文时经 `get_message` 获取）中的文字与图片，支持「前缀 + 仅图片」触发。单张图片上限 20 MB，单次消息最多 5 张图片，超限时明确提示拒绝。
- **对话会话与轮数**：上下文仅保存在内存中（进程重启即清空）。群聊按「群 + 发言者」独立，默认最多 2 轮；好友私聊按发言者独立，默认最多 8 轮。达到轮数上限后的下一次提问严格视为新对话：清空旧上下文并作为第 1 轮。内存历史保留之前轮次的图片以支持追问，单个会话历史媒体总占用上限 50 MB，超限时裁剪最早轮次的媒体字节并保留文字占位。
- **新对话命令与并发/冷却**：`<前缀>新对话` / `<前缀>重置` / `<前缀>reset` / `<前缀>clear`（不区分大小写）清空发言者在当前会话的上下文并回复确认，受白名单限制但不消耗冷却。发言者冷却跨群与私聊全局计时，默认 30 秒（可配置，0 为关闭），冷却内重复触发不重置计时、不豁免 Bot Super User，回复含剩余秒数的简短提示且不消耗轮数。调用失败或超时回复简短错误提示，不计入轮数、不污染上下文，并退还本次冷却。同一发言者在当前会话已有请求生成中时，新触发直接拒绝并提示稍候。
- **回复渲染与增强选项**：正常回复一律通过宿主 `IPluginImages.RenderDocument` 渲染为终末地长文卡片（页脚左显 `模型 · effort`，右显 `[n/limit]`），渲染或发图失败时降级发纯文本（超长截断）。思考摘要（`includeThoughts`）与 Google Search 联网搜索默认均关闭，可在配置中开启：思考摘要置于正文顶部引用块加分隔线且不混入后续多轮正文；联网搜索带回引用时在正文末尾追加去重后的精简「参考来源」列表，最大条数可配置（默认 5）。
- **用量统计与日志**：每次对话调用按部署时区日期与模型在全局 schema `gemini_usage_daily` 中原子累加请求数、成功数、输入/缓存命中/输出/思考/总计 token 及按内置公开单价估算的美元成本（USD），在专有页面展示今日/近 7 天/近 30 天/全部总览（成本、请求数、Token 消耗、缓存命中率）及按模型、按日明细。日志按「触发对话 → API 开始响应 → 回复完成（含耗时、回复字数、token 用量、生成速度与估算成本）」精简记录，不重复输出。
