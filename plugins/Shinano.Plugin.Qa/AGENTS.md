# 有人问插件约定

插件 ID `qa`。通用约定见仓库根目录 `AGENTS.md`；本文件只记录本插件的业务规则。

- 群与群之间的数据隔离。
- 当前群群主、群管理员及 Bot Super User 可以新增、修改、删除词条；普通成员可以触发已有词条和查询。
- 支持文字全字匹配与正则表达式匹配。文字或图文回答通过“有人问 xx 你答 xxx”录入，音频、视频和文件回答通过引用对应消息并发送“记录有人问 xxxx”录入；这两种录入方式默认创建全字匹配词条。正则文字录入使用“RG有人问<表达式>你答<回答>”，正则媒体引用录入使用“记录RG有人问<表达式>”。
- 全字和正则词条统一按创建先后排序，不区分匹配方式，越晚创建优先级越高，不提供优先级配置；命中多条时只回复最高优先级一条。
- 指令在当前群列出、增加、删除词条；Web 面板列出全部词条并支持筛选、增加和删除。面板新增词条的回答由文字、@ 与上传文件按顺序组成，可以同时包含多个文件，发送时每个文件各自上传为群文件。
- 回答可包含文本、图片、@（用于借助有人问找到某人）、音频、视频和文件，以完整消息段 JSON 保存；实际发送不支持或难以实现的类型经实测后移除。所有回答媒体须先存为持久媒体并登记词条引用，未成功则整条录入失败；删除或覆盖词条时删除对应引用。
- 检测到重复词条后进入连续对话，展示问题、原回答和新回答，询问是否覆盖。等待期间只接受发起人在同群发送的 `y` 或 `n`（不区分大小写），其他消息不被消耗；等待时间可在插件配置修改，默认 60 秒；回复 `n` 或超时保留原词条且不回复，只在覆盖的结果（成功或失败）上回复；等待期间同一人再次录入时由 Sora 的防重入占用该消息，不另行提示。回复 `y` 时若原词条已被他人修改或删除，则放弃覆盖并告知。覆盖后的词条视为最新创建。
- 正则词条的回答为固定内容，不使用捕获组；表达式无法编译时回复错误原因；每次匹配设置超时（默认 100 毫秒），超时视为未命中并告警。
- 禁止提问词由维护者在 Web 面板按条目配置，不提供指令配置。录入时只检查问题文本（全字或正则表达式）是否与某个条目完全相同，相同则明确告知不能配置；不做其他匹配推断。
- 录入引用消息需要解析实际回答内容并持久化媒体，不能仅保存引用消息 ID 或 IM 临时链接。录入人需具备管理权限，被引用消息可来自任何人；引用未内嵌正文时通过 `get_message` 获取，失败则回复无法获取并录入失败。支持文本、图片、@、音频、视频、文件及其组合，整条消息作为回答；含其他类型时回复「叽里咕噜说啥呢」，不录入。
