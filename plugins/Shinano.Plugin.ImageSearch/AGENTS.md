# 搜图插件约定

插件 ID `image-search`。网关客户端、SauceNAO 解析与分级判定在共享库 `plugins/Shinano.Plugin.ImageSources`（见其 `AGENTS.md`）。通用约定见仓库根目录 `AGENTS.md`；本文件只记录本插件的业务规则。

- 「搜图」「搜番」在群聊与私聊可用。图片取自指令消息本身、引用的消息（引用未内嵌正文时经 `get_message` 获取），否则提示并等待发起人发图（时间可配置，默认 60 秒，其他消息不被消耗）；多张图只搜第一张。取得图片后先回复确认收到（用户发出的图片也可能被腾讯按内容摘要拦截而 Bot 收不到），再开始搜索。冷却按会话与发送者、两条指令各自 20 秒（常量），从回复结果后开始计时，冷却中回复提示。
- 搜索与原图都经图源服务 YukariApiNext 转发：插件上传图片，网关原样返回 SauceNAO、IQDB、trace.moe 的响应；SauceNAO 等上游凭据由网关持有，插件只在机密中持有网关令牌，网关地址在插件配置中。网关不负责结果解析与分级，二者由插件完成。
- 每个搜索服务都取相似度最高的一条结果；Pixiv 信息最优先：SauceNAO 达到阈值的结果中有指向 Pixiv 作品的（结果本身或来源链接是 Pixiv）时，取其中相似度最高的一条（同一张图常同时出现在 Pixiv 与图站中、相似度几乎相同），搜图与 Hso 补全共用此规则（`ImageSources` 的 `HitPicker`）。搜图以 SauceNAO 为主（阈值默认 60%），搜番以 trace.moe 为主（阈值默认 90%）；主服务完成搜索时总是回复其最高结果，低于阈值只标为警告色，没有结果时回复没找到。兜底只在主服务不可用（出错、额度用完或未配置）时查询，查询前先回复「搜索服务爆炸了喵，在尝试别的方式喵」：搜图以 IQDB 兜底（阈值默认 80%；高负载时排队很久，请求超时放宽为 180 秒；排队后返回的读取失败页是上游的间歇性问题且不计额度，重试一次，仍失败视为失败），搜番以 SauceNAO 的番剧库兜底，规则相同；都不可用时按主服务的原因回复文案。每次调用搜索服务在日志记录 HTTP 状态码、耗时、最高相似度与其标题。
- 搜索只检索能取到原图的库（`ImageSources` 的 `SearchDatabases`），请求时经图源服务的 `db` 查询参数限定（取值为 SauceNAO 的 index 与 IQDB 的 service 编号），解析时也只保留这些库的结果，避免取不到原图的站占满结果：搜图的 SauceNAO 只查 Pixiv、Danbooru、Yande.re、Gelbooru、Sankaku（Hso 补全相同），IQDB 只查 Danbooru、yande.re、Gelbooru、Sankaku、e-shuushuu；搜番兜底的 SauceNAO 只查 Anime 与 H-Anime 库，H-Anime 结果按 R-18 处理。搜图只回复插画结果，番剧用「搜番」。部分作品（如 AI 作品）不在这些图库中，且正确结果的相似度也可能只有 40% 左右：搜图的插画图库完成搜索但没有结果或最高结果低于阈值时，再用 SauceNAO 检索全部库（多用一次额度；插件配置可关闭，默认开启），两次结果合并后取相似度最高的一条（相同时插画图库在前）；它不在插画图库中时只发基础信息卡（搜索结果中的来源名、标题、作者与作品号），不查来源作品、不下载原图；全部库没有完成搜索时只用插画图库的结果。
- 插画结果先查来源作品，再发卡片（宿主信息卡，不含链接），之后下载原图；番剧结果直接发卡片。卡片的标签为搜索服务，相似度以百分比与刻度显示并标出阈值；插画卡片为来源名、标题、作者、作品号与 `TAG`（每个标签一个方框，原值显示不翻译，最多显示的个数可配置，默认 20）：来源作品查到 Pixiv 时，来源名、标题、作者、作品号与标签都用 Pixiv 的作品信息，查不到 Pixiv 时用搜索结果中的信息与查到的图站帖子的标签，都查不到时没有标签；已知为成人内容的结果（IQDB 的 Explicit）不查来源作品。番剧卡片为番名（trace.moe 的繁体中文名原样显示，没有时用日文名）、集数、时间点与来源库；相似度低于阈值时为警告色并在页脚提示。卡片之后下载原图并发到同一会话，非成人番发 trace.moe 的画面预览；R-18 时以「H是不行的」替代图代替原图或预览（嵌入共享库 `Shinano.Plugin.ImageSources`）。下载期间每秒在日志记录进度与速度。
- 原图按结果中的来源顺序 Pixiv → Danbooru → Yande.re → Gelbooru → Sankaku → e-shuushuu 取第一个查得到的作品；结果或图站帖子的作品信息标注来源为 Pixiv 时，原图经 Pixiv 代理获取并按 Pixiv 信息判定 R-18，Pixiv 查不到才用图站原图与分级。R-18 判定：Pixiv 为 `x_restrict > 0` 或 R-18/R-18G 标签，booru 与 Sankaku 为分级 e/explicit，IQDB 标注 Explicit 的结果同样按 R-18 处理。结果中只有 Konachan 等取不到原图的来源时只发卡片。
- 原图从网关流式转存到插件独立 bucket（用途 `search`），以预签名链接发送：20 MB 以内作为图片，超过 20 MB 上传为群文件或私聊文件；大小上限可配置（默认 100 MB）。图片被拒（腾讯按内容摘要拦截）时改动一个随机像素、按原格式重新编码后重发一次，仍失败则放弃。发送成功的对象保留供宿主归档经同一链接读取，未发出的立即删除；后台任务每小时删除超过 1 小时的对象。原图失败不影响已发出的卡片。
