# 娱乐插件约定

插件 ID `entertainment`，包含骰子、随机选择与娱乐禁言。通用约定见仓库根目录 `AGENTS.md`；本文件只记录本插件的业务规则。

- 骰子：`dice` 全字匹配，群聊与私聊可用；点数 1–6 均匀分布；群聊回复「@发送者 丢出了\r\n<点数>」，私聊回复「丢出了\r\n<点数>」。
- 随机选择：以「选择」开头且含「还是」，群聊与私聊可用。Sora 只用文本段做正则匹配，图片选项靠正则判断不了，所以指令不在匹配后阻断，由处理方法按消息段拆分：选项有效才回复并占用消息，无效时不回复也不占用，后续指令照常处理。
  - 只接受文本、图片与 QQ 表情段，含引用、语音、文件、合并转发、@ 等其他段时不响应。
  - 第一个文本段去掉开头空白后须以「选择」开头；按文本中的「还是」把整串消息段切成选项，每个选项去掉首尾空白，既无文字也无图片的丢弃，图文混合的作为一个整体；有效选项少于 2 个时不响应，重复选项保留。
  - 回复「你的选项有：」逐行列出编号选项，最后「建议你选择：<被选中选项的完整消息段>」；按配置的概率（默认 10%）改为只回复文字「建议你选择：我全都要」。图片直接转发收到的图片段。
- 娱乐禁言：`优质睡眠`、`昏睡红茶`、`昏睡套餐`、`健康睡眠` 全字匹配，只在群聊，把发送者禁言配置的时长（分钟，默认 480，范围 1–43200）。
  - LLBot 对没有权限、实际未生效的禁言同样返回成功，所以调用前按双方群角色判断：群主可禁言管理员与普通成员，管理员只能禁言普通成员，群主不能被禁言。Bot 的角色不走缓存查询，发送者角色取自消息事件。
  - 没有权限、查询角色失败或接口返回失败时回复「我没有权限让你睡觉」，原因记入日志。
- 触发词与文案固定在代码中；不加冷却。
