# 切噜插件约定

插件 ID `cheru`。通用约定见仓库根目录 `AGENTS.md`；本文件只记录本插件的业务规则。

- 编码：`切噜一下<文本>`，群聊与私聊可用，只接受纯文本消息。每段连续的非空白字符（汉字、字母、数字、网址、标点、emoji）整体用 GB18030 编码为一个切噜词，空白原样保留；每个字节先低 4 位、后高 4 位，映射到字符集「切卟叮咧哔唎啪啰啵嘭噜噼巴拉蹦铃」，词首加「切」。回复「切噜～<结果>」。
- 切噜词格式与 HoshinoBot 相同，双方的解码器可以互相解出原文；与 HoshinoBot 不同的是不保留非汉字原文。
- 解码：`切噜~` 或 `切噜～<切噜语>`，群聊与私聊可用，只接受纯文本消息。只解码整段都是切噜字、以「切」开头的词，其余内容原样保留；长度为奇数时末尾那个字原样保留。回复「切噜的意思是:<结果>」。
- 需要注册 `CodePagesEncodingProvider` 才能使用 GB18030。
- 不声明配置类型，面板显示「无可配置项」。
