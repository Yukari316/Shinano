# Hso 图库插件约定

插件 ID `hso`。与搜图共用 `plugins/Shinano.Plugin.ImageSources`。通用约定见仓库根目录 `AGENTS.md`；本文件只记录本插件的业务规则。

- 图片只来自插件独立媒体（bucket 用途 `hso`）中的本地图库，随机选取；图库表在全局 schema，切换账号后共享，群设置与发图计数按账号隔离。图源服务只保留代理下载等转发接口，不再提供随机图片和图片存储，Hso 不调用远程随机图接口。
- 发图与排行（「来点色图」「来点涩图」「我要看色图」「来点色批」）只在群聊，屏蔽的群中静默不响应；冷却按群与发送者 20 秒（常量），从触发时开始计时，冷却中回复提示；图片发出后才计入排行，图库为空、冷却中与发送失败不计数。排行为前 10 名的排行卡片，名称取群名片（没有时用昵称），不 @ 任何人。
- 本地图库来自 Web 上传（多张图片或 zip）、`Shinano.Tool hso-import --dir <目录>` 从部署机目录导入，以及 Super User 通过 `AD<pid> <页号>`（页号从 0 开始，群聊与私聊）由插件经图源服务代理下载 Pixiv 作品导入；不实现定时批量抓取。按内容 SHA256 去重，只接受 JPEG、PNG、GIF、WebP，不因超过 20 MB 拒绝导入。
- 本地图片记录 pid 与页号：`AD` 导入天然带 pid；上传与工具导入按 `<pid>_p<页号>.<ext>` 解析，不符合命名的记为无 pid。图库为空时回复简短提示。
- 作品信息在后台补全，不阻塞发图（`AD` 导入时为判断作品与页号已经查询，直接确认）：抽到待补全的图片时照常发图、不发信息卡，并在后台补全；另有后台任务每天补全最早导入的若干张（默认 5 张，插件配置可改，0 为关闭；每小时分摊执行）。有 pid 时查 Pixiv，没有 pid 时用 SauceNAO 以图搜图（阈值可配置，默认 80%，Pixiv 结果优先，规则同搜图）；来源作品查到 Pixiv 时（包括经图站帖子标注的来源查到），来源名、pid、标题、作者与标签都用 Pixiv 的作品信息，图站结果的标题字段常是作品出处、作者是图站画师标签。结果（标题、作者，Pixiv 另有作者 ID 与标签）存入数据库，之后发送不再访问接口；查询失败之后再查，查无结果不再查询。作品数据的限制级别 `x_restrict` 大于 0，或标签中含 `R-18`/`R-18G`，任一项成立即为 NSFW；图站按分级 e/explicit；没有作品信息的图片默认非 NSFW。管理员可在 Hso 图库页逐张修改 NSFW 标记，改过的不被补全覆盖。
- 查到作品信息后下载来源原图（Pixiv 按 pid 与页号，图站取查到的帖子），与图库图片比较 SHA256：一致视为同一张图，信息直接确认；不一致（多为文件名不带 pid、经 SauceNAO 匹配的图）或原图下载失败时进入审核队列，来源原图暂存在插件 bucket 的 `reviews/` 下直到处理。待审核期间不发信息卡，NSFW 按查到的信息判定。查完不补发信息卡，下次抽到才发。只对新补全的图片比较。
- 审核在 Hso 图库页以单独小窗按队列逐张处理（顶部「审核队列（n）」打开），左右对比图库中的图片与查询获取的原图（格式、尺寸、大小、SHA256），下方为查到的作品信息；处理后自动进入下一张，可跳过；处理按钮均为纯色按钮。三种处理：覆盖（以来源原图替换图库对象并确认信息，清除被拦截标记、删除旧对象；与图库中另一张相同时不覆盖并提示）；只确认信息（保留图库图片）；否决（丢弃查到的信息，可手动补全标题、作者、UID、PID、页号、标签与 NSFW，全部留空记为查无信息；SauceNAO 查到的 pid 一并作废，NSFW 恢复默认，管理员手动设置过的不变；之后不再自动查询）。
- 不允许 NSFW 的群只从未标为 NSFW 的图片中抽取。插件配置「补全缺失的图片信息时是否发送 NSFW 图片」（默认关闭）：关闭时，这类群抽到待补全（尚不能确定是否 NSFW）的图片不发送，转为后台补全并改抽一张不是待补全的非 NSFW 图片；开启时照常发送。没有可发的图片时按图库为空回复。允许 NSFW 的群不受影响。
- 不使用合并转发：先发图片，作品信息已确认时再发作品信息卡（宿主信息卡：标题、作者、`UID`（Pixiv 作者 ID）、`PID`、`TAG`（每个标签一个方框，有中文翻译时显示翻译，否则显示原文），没有的项不显示；待补全、待审核与查无信息时不发）。超过 20 MB 的图片改为群文件。图片被拒（腾讯按内容摘要拦截）时改动一个随机像素另存为临时对象重发，成功则标记该图，之后每次发送都直接改像素；图库对象本身不替换，面板可清除标记；仍失败回复失败文案。临时对象保留供宿主归档读取，后台任务每小时删除超过 1 小时的。
- 图库页从上到下为审核队列入口、上传、群设置（屏蔽、是否允许 NSFW，新群默认不屏蔽、不允许 NSFW）、筛选搜索与网格图库（待审核的图片标注「待审核」）；每页 20 张，缩略图由服务器即时绘制不保存，点击查看原图。
- 迁移群屏蔽列表与调用排行；`让我康康` 占位指令不迁移。图源服务（YukariApiNext）提供作品信息查询、按 pid 与页号的代理下载与 SauceNAO 转发；服务地址在插件配置中设置（默认 `https://api.kosaka-wakamo.top/`），访问令牌存于插件机密。搜图插件使用同一服务，地址与令牌独立配置；两者共用 `plugins/Shinano.Plugin.ImageSources` 中的网关客户端、SauceNAO 解析与分级判定。
